# 🎪 סוכן האינסטגרם של קרקס בראבו

סוכן AI שמנהל את עמוד האינסטגרם של קרקס בראבו – לבד, כל יום:

| מה | מתי | איך |
|---|---|---|
| **מתכנן פוסטים + מייצר תמונות ב-AI** | כל בוקר, ל-3 הימים הקרובים | Claude כותב את הטקסט, ותמונה חדשה נוצרת ב-AI (או נבחרת מתמונות שהעליתם ל-`media/`) |
| **מעדכן את לוח ההופעות מקופת תל אביב** | כל בוקר | קורא את עמוד הקרקס באתר הקופה – תאריכים, שעות, ערים, אולמות וקישורים |
| **מפרסם פוסט** לאינסטגרם | כל יום בשעה שנקבעה (ברירת מחדל 18:00) | Instagram API |
| **עונה ללקוחות** בתגובות (ובהודעות פרטיות – אופציונלי) | כל 30 דקות | Claude עונה לפי `brand/brand.md` |
| **"מחר אנחנו מגיעים ל..."** – פוסטר אוטומטי לכל עיר + קישור מכירה בקופת תל אביב | כל יום, יום לפני כל הופעה (ברירת מחדל 10:00) | לפי לוח ההופעות ב-`content/tour.yaml` |
| **מעביר אליכם** תלונות / החזרים / פניות עסקיות | מיד | נפתח Issue בגיטהאב (מגיע אליכם במייל) |
| **מסתיר ספאם** | מיד | |

הכל רץ בחינם על **GitHub Actions** – אין שרת.

---

## 🚀 הפעלה (פעם אחת, ~20 דקות)

### 1. חשבון אינסטגרם מקצועי
האינסטגרם של הקרקס צריך להיות **Business** או **Creator** (בהגדרות האינסטגרם ← סוג חשבון).

### 2. אפליקציה ב-Meta וטוקן
1. נכנסים ל-https://developers.facebook.com/apps ← **Create App** ← סוג **Business**.
2. מוסיפים את המוצר **Instagram** ← **API setup with Instagram login**.
3. ב-"Generate access tokens" מוסיפים את חשבון האינסטגרם של הקרקס ולוחצים **Generate token**.
   הרשאות נדרשות: `instagram_business_basic`, `instagram_business_content_publish`, `instagram_business_manage_comments`
   (ולהודעות פרטיות גם `instagram_business_manage_messages`).
4. מעתיקים את **הטוקן** ואת **Instagram User ID** (מופיע ליד שם החשבון).

### 3. מפתח Claude
https://console.anthropic.com ← API Keys ← Create Key.

### 3ב. מפתח ליצירת תמונות (OpenAI)
https://platform.openai.com/api-keys ← Create new secret key. מטעינים קרדיט ב-Billing (תמונה עולה בערך 5–10 סנט).
אם OpenAI מבקש **Verify organization** – מאשרים (נדרש לשימוש במודלי התמונות).

### 4. שמירת הסודות בגיטהאב
בריפו: **Settings ← Secrets and variables ← Actions ← New repository secret**:

| שם | ערך |
|---|---|
| `IG_USER_ID` | ה-ID של חשבון האינסטגרם |
| `IG_ACCESS_TOKEN` | הטוקן מ-Meta |
| `ANTHROPIC_API_KEY` | המפתח של Claude |
| `OPENAI_API_KEY` | המפתח של OpenAI – לתמונות AI |
| `GH_PAT` *(מומלץ)* | [Personal access token](https://github.com/settings/personal-access-tokens) עם הרשאת Secrets: write לריפו הזה – כדי שהטוקן של אינסטגרם יתחדש לבד כל שבועיים (בלי זה הוא פג אחרי 60 יום) |

### 5. למלא את המידע על הקרקס
עורכים את **`brand/brand.md`** ומשלימים כל מקום שכתוב **[להשלים]** – שעות, מחירים, קישור לקופה, גילאים.
**הסוכן עונה ללקוחות רק לפי מה שכתוב שם.**

### 6. תמונות וסרטונים (לא חובה)
עם מפתח OpenAI הסוכן מייצר תמונות לבד. אם יש לכם תמונות אמיתיות מהמופע – העלו גם אותן, הסוכן ישלב.
מעלים לתיקייה **`media/`** (Add file ← Upload files).
- תמונות: **JPG** בלבד · סרטונים (רילס): **MP4**
- שם קובץ באנגלית, בלי רווחים (למשל `juggler-rehearsal.jpg`)
- כמה שיותר – לפחות 7 לשבוע. אם נגמרות תמונות חדשות, הסוכן ישתמש שוב בישנות עם טקסט חדש.

### 7. ניסוי יבש ואז הפעלה
1. **Actions ← תכנון פוסטים לשבוע ← Run workflow** – הסוכן יכתוב פוסטים ל-`content/queue.yaml`. בודקים שזה נראה טוב.
2. **Actions ← מענה לתגובות והודעות ← Run workflow** – בלוג רואים מה הוא *היה* עונה (עדיין לא שולח כלום).
3. כשמרוצים: **Settings ← Secrets and variables ← Actions ← Variables** ← מוסיפים `DRY_RUN` = `false`. מעכשיו הוא חי ✅

## 🎪 לוח ההופעות – פוסט "מחר אנחנו מגיעים"
הלוח (**`content/tour.yaml`**) מתעדכן לבד כל בוקר מעמוד הקרקס באתר **קופת תל אביב**. אין צורך לערוך אותו ידנית – רק אם רוצים להוסיף `poster` או `note` להופעה (אלה נשמרים בעדכון).
- רקע הפוסטר נוצר ב-AI, והטקסט בעברית (עיר, תאריך, שעות) מודפס עליו בצורה מדויקת.
- כל יום ב-06:17 הסוכן בודק אם יש הופעה מחר, מייצר פוסטר (`media/tour/`) וכותב טקסט עם הקישור.
- הפוסט עולה באותו יום ב-`post_time` (או במשתנה `TOUR_POST_TIME`).
- כמה הופעות באותה עיר ביום = פוסט אחד עם כל השעות.
- רוצים פוסטר מעוצב משלכם? מעלים ל-`media/` ורושמים `poster: file.jpg` להופעה. אפשר גם `poster_base` = תמונת רקע לכל הפוסטרים.
- ⚠️ קישורים בטקסט של פוסט באינסטגרם לא לחיצים – לכן הפוסט אומר "קישור בביו". כדאי לשים בביו את עמוד הקרקס בקופת תל אביב.
- בימים שיש בהם פוסט כזה, התכנון השבועי לא מוסיף פוסט נוסף.

## 🌺 סוכן שיווק – תוכנית קמפיין (הוואי פארק ועוד)
סוכן נפרד שבונה **תוכנית שיווק מלאה לעונה**: אסטרטגיה וקהלים, שלבי קמפיין, **שפה גרפית** (פלטה, פונטים, מוטיבים, קמע, קי-ויז'ואלים), **התאמת המוצר לכל חג**, לוח תוכן שבועי, ערוצים ותקציב, מדדים וסיכונים.

- התדריך: **`campaigns/hawaii-park/brief.yaml`** – ממלאים כל מקום שכתוב **[להשלים]** (מחירים, שעות, מתקנים, תקציב). הסוכן לא ממציא – מה שחסר מופיע אצלו כ"שאלה פתוחה".
- הפעלה: **Actions ← סוכן שיווק – תוכנית קמפיין ← Run workflow** (אפשר להוסיף הנחיות, ולסמן "קי-ויז'ואלים" ליצירת תמונות ב-AI).
- התוצרים (בתיקיית הקמפיין): `plan.md` התוכנית · `graphic-language.md` השפה הגרפית · `calendar.yaml` לוח שבועי · `style-board.html` לוח ויזואלי · `visuals/` קי-ויז'ואלים.
- התאריכים (שבועות, חגים, ימי זיכרון) מחושבים בקוד ולא על ידי המודל. ביום השואה וביום הזיכרון – בלי תוכן חגיגי.
- עריכה ידנית: משנים את `plan.json` ומריצים `python -m agent.main marketing --rerender` – כל הקבצים נבנים מחדש בלי לקרוא למודל.
- קמפיין חדש: מעתיקים את התיקייה לשם חדש תחת `campaigns/`, מעדכנים את `brief.yaml`, ומריצים עם שם הקמפיין.
- משתנה `MARKETING_MODEL` (ברירת מחדל `claude-opus-5-5`) – המודל שכותב את התוכנית.

## ⚙️ הגדרות (Variables)

| משתנה | ברירת מחדל | מה עושה |
|---|---|---|
| `DRY_RUN` | `true` | `false` = מפרסם ועונה באמת |
| `AUTO_APPROVE` | `true` | `false` = פוסטים נכנסים כטיוטה, ומאשרים ידנית ב-`queue.yaml` (`approved: true`) |
| `ENABLE_DMS` | `false` | `true` = עונה גם להודעות פרטיות (דורש הרשאת messages) |
| `WEEKLY_BRIEF` | — | הנחיה קבועה לתכנון, למשל "להתמקד במכירת כרטיסים לחנוכה" |
| `TOUR_POST_TIME` | `10:00` | באיזו שעה עולה פוסט "מחר אנחנו מגיעים" |
| `CLAUDE_MODEL` | `claude-sonnet-5-5` | המודל שכותב ועונה |
| `USE_AI_IMAGES` | `false` | `true` = הסוכן מייצר תמונות חדשות ב-AI. כברירת מחדל הוא משתמש רק בפוסטרים של הקמפיין שב-`media/` |
| `IMAGE_MODEL` | `gpt-image-2` | המודל שמייצר תמונות (רק אם USE_AI_IMAGES=true) |

## ✏️ שליטה ידנית
- **לשנות/למחוק פוסט מתוכנן** – עורכים את `content/queue.yaml` (טקסט, שעה, תמונות, `approved`).
- **הנחיה לשבוע ספציפי** – Run workflow על "תכנון פוסטים לשבוע" וכותבים בשדה "הנחיות לשבוע".
- **פניות שהועברו אליכם** – לשונית **Issues**. מומלץ להפעיל Watch על הריפו כדי לקבל אותן במייל.

## 🗂️ מבנה
```
agent/           קוד הסוכן (instagram.py – API, brain.py – Claude, main.py – פקודות, marketing.py – סוכן השיווק)
campaigns/       תוכניות קמפיין (תדריך + תוכנית + שפה גרפית)
brand/brand.md   הידע והטון של המותג
content/queue.yaml  תור הפוסטים
media/           תמונות וסרטונים לפרסום
state/           מה כבר נענה (מתעדכן אוטומטית)
.github/workflows/  התזמונים
```

הרצה מקומית: `pip install -r requirements.txt && python -m agent.main check`
